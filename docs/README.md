## 📝 Bidra till dokumentationen

### Skapa ny dokumentation
1. Använd Markdown-format
2. Följ befintliga namnkonventioner
3. Uppdatera denna översiktsfil
4. Använd relativa länkar

### Uppdatera dokumentation
1. Håll dokumentation synkroniserad med kodändringar
2. Uppdatera API-dokumentation vid ändringar
3. Revidera användarguide vid nya funktioner

### Stilriktlinjer
- Använd svenska som primärt språk
- Var konsekvent med terminologi
- Inkludera exempel och kodsnippets
- Använd tabeller för jämförelser
- Inkludera diagram där det hjälper förståelsen
